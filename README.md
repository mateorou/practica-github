# practica-github
1. Creación y compartición de repositorios de código

Práctica de GitHub
Este repositorio lo he creado para practicar cómo funciona GitHub y aprender a usar el control de versiones en un proyecto de clase. Aquí guardo los archivos que he subido, y los cambios que he ido registrando con commits durante la actividad.
El README sirve como una pequeña presentación del proyecto. Básicamente explica de forma rápida qué es este repositorio, qué contiene y quién lo ha hecho. Es como una guía corta para que cualquiera que entre aquí entienda de qué va todo sin tener que mirar archivo por archivo.
